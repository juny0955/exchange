# Issue Convention

## Title Format
`이슈 요약` (예: `사용자 잔액 조회 API 구현`, `OrderEventConsumer DLT 핸들러 누락`)

## Template

```markdown
## Why
해당 이슈를 생성하는 이유와 배경. 현재 문제점 또는 기능 필요성을 서술한다.

## Scope

### 1. [작업 단위 제목]
- [ ] 세부 작업 항목
- [ ] 세부 작업 항목

### 2. [작업 단위 제목]
- [ ] 세부 작업 항목
- [ ] 세부 작업 항목

## References
- 관련 PR: #N
- 참고: `패키지/경로/파일.java` (설명, L행~L행)
```

## 작성 가이드
- **Why**: 문제 원인 또는 필요성을 한두 문단으로 명확히 기술한다.
- **Scope**: 작업을 독립적인 단위로 나누고, 각 항목은 체크박스(`- [ ]`)로 작성한다. 옵션이 있을 경우 권장 옵션을 명시한다.
- **References**: 관련 PR, 이슈, 참고할 소스 파일 경로(라인 번호 포함)를 기재한다.
